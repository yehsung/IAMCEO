# 업그레이드·백업·제거

[English](upgrade-backup-uninstall.en.md) · [사용자 문서 목록](README.md)

아래 `iamceo`는 앱 안의 명령줄 도구(`/Applications/IAMCEO.app/Contents/Resources/runtime/iamceo`)입니다 → [시작하기](getting-started.md#명령줄-도구)

## 새 버전이 나왔는지 알기

- **Mac 앱:** 실행 중일 때 하루에 한 번 GitHub에 최신 릴리스를 묻습니다. 새 버전이 있으면 **설정 → 연결 → 앱**에 '새 버전 있음' 줄이 생기고, **받기**를 누르면 릴리스 페이지가 열립니다. 알리기만 하고 저절로 받거나 설치하지는 않습니다. 이 확인 요청에 무엇이 담기는지는 [개인정보 처리방침](../../PRIVACY.md)에 있습니다.
- **iPhone 앱:** App Store가 업데이트를 맡습니다.

## 새 버전으로 올리기

설치한 방법대로 올립니다. 어느 방법이든 데이터(`~/.iamceo`)는 그대로입니다.

| 설치한 방법 | 올리는 법 |
|---|---|
| Homebrew | `brew upgrade --cask iamceo` |
| 설치 스크립트·DMG | IAMCEO 앱을 종료한 뒤 `iamceo upgrade` (또는 설치 스크립트를 다시 실행하거나 새 DMG의 앱으로 바꿉니다) |

`iamceo upgrade`는 다음 순서로 바꿉니다.

1. 최신 릴리스(또는 `--version v0.2.4`처럼 정한 버전)를 받아 체크섬, 배포자 서명, Apple 공증을 확인합니다.
2. **지금 DB의 사본으로 새 버전을 미리 돌려 봅니다.** 원본은 읽기만 합니다. 미리 돌려 보기가 실패하면 아무것도 바꾸지 않습니다.
3. 직전 버전을 `~/.iamceo/upgrades/<번호>/`에 기록합니다(서비스 설정, DB 사본, 이전 앱).
4. 서버를 내리고 앱을 바꾼 뒤 다시 올려 준비됐는지 확인합니다. **정해진 시간 안에 준비되지 않으면 스스로 직전 버전으로 되돌립니다.**

`iamceo upgrade --dry-run`은 무엇을 할지 보여 주기만 합니다. 실행 중인 앱은 바꾸지 않으므로 먼저 앱을 종료합니다. Homebrew로 설치한 앱은 Homebrew 기록과 맞도록 `brew upgrade`로 올리라고 안내합니다. 지금보다 낮은 버전으로는 바꾸지 않습니다. 돌아가려면 아래 `iamceo rollback`을 씁니다.

### 앱을 바꾼 뒤의 서버

Homebrew·설치 스크립트·DMG로 앱만 바꾸면, 서버는 다시 시작하기 전까지 옛 버전으로 계속 돕니다. Mac 앱이 이것을 알아보고 **서버를 새 버전으로 다시 시작할까요?**를 한 번 묻습니다. **다시 시작**을 누르면 앱에 든 새 서버로 바꿉니다. 나중에 하려면 **설정 → 연결 → 접속**의 '새 버전으로 다시 시작' 줄을 씁니다. 팀장 세션은 실행 엔진이 붙잡고 있어 서버가 다시 시작해도 이어집니다.

이 질문은 앱이 직접 관리하는 설치(앱으로 설치하고 **이 Mac에서 시작**으로 등록한 서버)에서만 나옵니다. 소스에서 직접 띄운 서버에는 묻지 않습니다.

### 앱과 서버가 맞지 않을 때

앱과 서버가 실제로 맞지 않을 때만 안내가 뜹니다. '앱을 업데이트하세요'는 앱이 오래된 경우, '서버가 옛 버전입니다'는 서버가 오래된 경우입니다. 그 밖에는 버전이 달라도 아무것도 띄우지 않습니다.

## 직전 버전으로 되돌리기

```sh
iamceo rollback --dry-run   # 무엇을 되돌릴지 먼저 봅니다
iamceo rollback
```

마지막 `iamceo upgrade` 전의 버전으로 돌아갑니다. 앱을 먼저 종료합니다.

- 새 버전이 DB 구조를 올렸다면, 업그레이드 전에 떠 둔 DB 사본으로 함께 되돌립니다. 이때는 `--yes`를 붙여야 진행합니다.
- 그 경우 **업그레이드 뒤에 쌓인 대화와 결재는 되돌린 DB에 들어가지 않습니다.** 지우지 않고 `~/.iamceo/upgrades/<번호>/` 안에 따로 남깁니다.
- 자동 되돌리기는 새 버전이 뜨지 못했을 때만 합니다. 이미 잘 돌고 있는 버전을 되돌릴지는 직접 정합니다.

## 백업

서버는 켜져 있는 동안 **하루에 한 번** `~/.iamceo/backups`에 검증한 백업을 만듭니다. 일별 7개와 주별 4개를 남깁니다. 마지막 백업이 언제인지는 점검표의 백업 항목(`iamceo doctor`)에 나옵니다.

| 백업에 들어가는 것 | 들어가지 않는 것(따로 보관) |
|---|---|
| DB(대화, 결재, 할 일, 업무, 자료 목록, 설정) | 프로젝트 작업 폴더의 파일(내 코드는 git 등으로 따로) |
| 대화와 자료가 쓰는 첨부 파일 | Claude Code·Codex의 로그인과 세션 기록 |
| `config.json`(접속 코드 포함), 있으면 `apns.json` | iPhone 알림 키(`.p8`) |

- 백업은 파일마다 해시를 적고 DB 무결성을 검사합니다.
- **백업에는 접속 코드가 그대로 들어 있습니다.** 다른 곳으로 옮기면 비밀번호처럼 다룹니다. QR로 연결한 기기의 열쇠는 해시만 들어갑니다.
- 백업은 같은 디스크에 있으므로 디스크 고장에는 대비하지 못합니다. 가장 최근 `snapshot-<번호>` 폴더를 외장 디스크 같은 다른 곳에 복사해 두세요.
- `iamceo backup`은 데이터 폴더를 혼자 쓸 수 있을 때만 됩니다. 서버가 켜져 있으면 거절되므로, 그때는 서버가 매일 만드는 백업을 씁니다.

## 새 Mac에서 백업으로 시작하기

새 Mac으로 옮기거나 Mac을 다시 설치했을 때, 백업에서 대화·결재·자료를 되살립니다.

1. **옛 Mac에서** 가장 최근 백업 폴더(`~/.iamceo/backups/snapshot-<번호>`)를 새 Mac으로 복사합니다. 옛 Mac을 계속 쓸 생각이 아니면, 복사한 뒤 옛 Mac에서 `iamceo uninstall`로 IAMCEO를 멈춥니다(데이터는 남습니다).
2. **새 Mac에서** IAMCEO, Claude Code(로그인까지), 필요하면 Codex와 Tailscale을 설치합니다. 아직 **이 Mac에서 시작**은 누르지 않습니다.
3. 앱이 쓰는 데이터 폴더(`~/.iamceo`)로 복원합니다. 복원은 비어 있는 폴더에만 되고, 발신을 꺼 둔 채로 만듭니다.

   ```sh
   iamceo restore ~/Desktop/snapshot-<번호> --destination ~/.iamceo
   iamceo restore reconcile
   iamceo restore resume
   ```

   `reconcile`은 백업을 만들 때 진행 중이던 전달과 알림을 보수적으로 정리하고, `resume`은 그 뒤에 발신을 허용합니다. 둘 다 서버나 AI를 직접 띄우지 않습니다. 옛 Mac과 새 Mac을 함께 쓸 생각이면 `--clone`을 붙여 새 서버로 복원합니다. 복제본은 옛 Mac에 연결돼 있던 기기의 열쇠를 받지 않고, 접속 코드도 새로 만듭니다(`iamceo open`으로 확인).
4. IAMCEO 앱을 열고 **이 Mac에서 시작**을 누릅니다. 복원한 데이터와 접속 코드로 서버가 등록됩니다.
5. 프로젝트의 작업 폴더(내 코드)를 새 Mac의 같은 자리에 두거나, 프로젝트 관리에서 폴더를 새 자리로 바꿉니다. CLI의 세션 기록은 백업에 없으므로 팀장은 새 세션으로 열립니다.
6. iPhone은 주소가 바뀌었으므로 새 QR로 다시 연결합니다. 알림을 쓰던 기기는 알림을 다시 켭니다.

## 기록은 얼마나 남나

- **대화, 결재, 할 일, 자료는 내가 지우기 전까지 남습니다.**
- 서버가 안에서만 쓰는 기록은 기한이 지나면 스스로 정리합니다. AI 세션에 넣은 글의 사본은 그 전달이 끝나고 30일 뒤에 비우고(무엇을 보냈는지의 해시는 남깁니다), 실행 기록과 처리 영수증은 끝나고 90일 뒤에 지웁니다. 끝나지 않은 일의 기록은 지우지 않습니다.
- 서버 로그는 크기가 차면 지난 파일로 넘어가며, 몇 개만 남깁니다. 진단 파일은 가장 최근 다섯 개만 남깁니다.

## 프로젝트 내보내기와 지우기

보관함에 넣은 프로젝트는 프로젝트 단위로 내보내거나 지울 수 있습니다.

- **내보내기:** 그 프로젝트의 대화, 결재, 할 일, 업무, 자료와 첨부 원본을 zip 파일 하나로 받습니다. 접속 코드, 팀장 열쇠, 전달 내부 기록은 넣지 않습니다. 이 Mac에서 연결한 앱에서만 됩니다. 대화 내용이 그대로 들어 있으니 보관에 주의합니다.
- **지우기:** 보관한 프로젝트만 지울 수 있습니다. 지우기 전에 한 번 더 확인하고, 지운 프로젝트는 되살릴 수 없습니다. 필요하면 먼저 내보냅니다. 그 프로젝트의 첨부 파일도 함께 지우고, 작업 폴더(내 코드)는 지우지 않습니다. 이미 만든 백업에는 지운 프로젝트가 남아 있다가, 오래된 백업이 차례로 지워지면서(길게는 약 4주) 사라집니다.
- 본사는 보관하거나 지울 수 없습니다.

## 이 Mac에서 완전히 멈추기(제거)

앱을 휴지통에 버리는 것만으로는 이미 떠 있는 서버와 AI 세션이 남을 수 있습니다. 먼저 IAMCEO를 완전히 멈춘 뒤 앱을 지웁니다.

- **앱:** 설정의 **이 Mac에서 완전히 멈추기**
- **명령줄:** `iamceo uninstall` (`--dry-run`으로 무엇을 할지 먼저 볼 수 있습니다)

차례는 이렇습니다.

1. 서버가 떠 있으면 IAMCEO가 관리하는 팀장을 모두 재웁니다. 내가 직접 띄워 붙인 세션은 건드리지 않습니다.
2. 로그인 항목으로 등록한 서버를 해제합니다(서버가 내려갑니다). 다른 설치의 서비스는 건드리지 않습니다.
3. 실행 엔진의 터미널을 모두 끝내고 엔진을 끕니다.
4. **데이터는 기본으로 남깁니다.** 지우려면 `iamceo uninstall --purge`를 쓰고, 한 번 더 확인합니다. 데이터 폴더(`~/.iamceo`)를 통째로 지우므로 **백업도 함께 사라집니다.** 필요한 백업은 먼저 다른 곳에 복사합니다.

그다음 앱을 지웁니다. Homebrew로 설치했다면 `brew uninstall --cask iamceo`, 아니면 응용 프로그램 폴더의 IAMCEO를 휴지통으로 옮깁니다. `brew uninstall --zap --cask iamceo`는 데이터 폴더까지 휴지통으로 옮깁니다.

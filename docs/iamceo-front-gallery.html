SYSTEM MAP / HERDR-CORE / DESIGN 2.0

공식 CLI는 그대로, 관리는 IAMCEO.

실행 기반은 herdr-core 하나로 확정했습니다. Mac·iPhone은 호스트의 IAMCEO 데몬에 직접 연결하고, 실제 터미널은 별도 holder가 보유합니다.

아키텍처 설계입니다. 실제 앱·서버 런타임은 아직 전환하지 않았습니다. 아래 흐름을 선택하면 관련 연결을 강조합니다.

DECISION / HERDR-CORE

Herdr TUI 전체 대신, 독립된 core를 사용합니다.

확정 방향 · 구현 전

herdr-core + IAMCEO 업무 데몬 + Swift 앱

공식 CLI의 실행 환경과 직접 터미널 접속을 보존합니다. core의 API·이벤트·holder를 사용하고, 업무·결재·자료·인계는 IAMCEO가 소유합니다. 기존 Paseo 추천안은 이 결정으로 대체합니다.

기존 Herdr TUI와 herdr-core는 별도 프로그램입니다. 현재 IAMCEO의 pane/workspace 어댑터는 새 terminal API로 이식해야 합니다. 엔진 선택 메뉴는 제공하지 않습니다.

기능은 유지하고, 수명은 분리

총괄은 기본 Claude이며 Codex로 시작·교체할 수 있습니다. 총괄을 바꾸어도 팀장은 유지합니다. CLI 간 교체는 새 세션에 목표·결정·자료·미완료 업무를 인계하고 담당권을 옮깁니다.

앱 종료, 업무 데몬 종료, core 재시작, holder 손실, Mac 재부팅은 서로 다른 복구 경로로 처리합니다.

상태 지원과 업무 완료는 구분

Claude Code 2.1.295와 Codex 0.163.0부터 OSC 7501 지원이 확인됩니다. 실제 상태 수신을 진단하며, idle·done만으로 전체 업무를 완료 처리하지 않습니다.

결재 내용·질문·자료는 구조화된 도구로 전달합니다. CLI 권한 응답이 검증되지 않은 경우 같은 앱의 원래 터미널에서 직접 처리합니다.

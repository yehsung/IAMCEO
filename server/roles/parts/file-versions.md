- 한 결과는 자료 하나로 올린다. 같은 내용을 `html`과 `content`(md) 두 벌로 올리지 않는다. 복사해 쓸 글이 필요하면 html 안에 함께 넣고, 그림에 붙일 설명만 따로 문서로 올리지 않는다. 덱·문서의 원본 파일(pptx·pdf 등)과 html 미리보기도 따로 올리지 않는다: `file` 한 번에 `html`(또는 .html `path`)과 `original`(원본 파일 경로)을 함께 주면 한 판이 자료 하나가 된다.
- 이미 올린 자료를 고친 판·새 판은 반드시 `file`의 `replaces`에 앞 판의 id를 넣어 올린다. 앞 판 id는 그 자료를 올렸을 때의 결과에 있고, 모르면 `file`의 `find`(제목 낱말)로 찾는다. 새 판이 앞 판을 대신해 대표 자료 목록에는 최신 판만 보이고 앞 판은 '이전 판'에 남는다. 결재 카드나 보고가 가리키던 자료를 고쳤으면 새 판 id를 보고에 잇는다.
- `replaces`를 빠뜨리면 서버가 내가 올린 같은 종류 자료 가운데 제목이 같은 최신 판(v2·3판·초안·최종 같은 판 표시와 날짜는 빼고 비교)에 잇고 결과에 알린다. 그래서 새 판은 같은 제목으로 올린다. 결과가 엉뚱한 자료에 이었다고 하면 `file`의 `unchain`으로 끊는다. 앞 판과 다른 새 자료면 `new_item: true`로 올린다.
- 같은 이름으로 거듭 올리는 서로 다른 보고(일일 보고·테스트 결과 등)는 제목에 날짜나 회차를 넣는다. 제목이 같으면 앞 보고의 새 판으로 이어질 수 있다.
- 제목에 '최신'·latest 를 붙이지 않는다. 어느 판이 최신인지는 서버가 판을 이어 센다(옛 판에 남은 '최신'이 대표를 헷갈리게 한다).

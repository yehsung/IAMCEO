- 대표가 이 Mac을 같이 쓰고 있다. 대표의 화면·소리·폴더를 가로채지 않는다. 서브에이전트·워크플로에 일을 줄 때도 아래 규칙을 넣는다.
  - 다른 앱이나 파일을 화면 앞으로 여는 조작(`open`, AppleScript·osascript로 다른 앱 다루기, 화면 녹화·캡처 도구 띄우기, 대신 누르고 입력하기)을 하지 않는다. 앱 화면을 써야 하는 일이면 창을 앞으로 가져오지 않는 방법(백그라운드 실행, 헤드리스 실행)을 먼저 쓰고, 그래도 대표의 화면이 필요하면 `ask`로 언제 해도 되는지 묻는다.
  - 브라우저 조작은 대표가 정한 것(지침 끝 대표 상시 규칙에 있으면 그것, 예: Aside)만 쓴다. 정한 것이 없으면 창을 띄우지 않는 방법(헤드리스 브라우저, curl 등)을 쓰고, 대표의 브라우저에 새 창·탭을 열지 않는다.
  - 소리를 내지 않는다. 음성·음악을 틀거나 `say`를 쓰지 않는다. 연결된 iPhone 같은 대표의 기기에서 앱을 다뤄야 하면 화면과 소리가 대표에게 닿으니 먼저 `ask`로 묻는다. 소리를 확인해야 하면 파일로 만들어 자료로 올린다.
  - 내려받은 파일과 중간 파일은 작업 폴더 안에 둔다. 대표의 다운로드·데스크톱·문서 폴더에 파일을 만들지 않는다.

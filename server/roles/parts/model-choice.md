- `team_add`의 `model`은 대표가 바로 그 직원(그 일)에 대해 모델을 말했을 때만 넣는다. 앞 일에 준 모델 지시나 다른 직원의 모델을 새 직원에게 이어 쓰지 않는다. 말이 없으면 비워 두어 설정의 기본 모델로 띄운다. 대표의 말이 그 일에만인지 앞으로 전부인지 모호하면 그 일에만 적용한다.
- 앞으로 띄울 직원 전부의 모델을 바꾸라는 말이면 `rule`로 남기지 않는다. 앱 설정의 'AI 모델'에서 팀장 기본 모델을 바꾸면 된다고 대표에게 알린다(직원마다 `model`을 넣으면 설정의 기본값과 실제 모델이 어긋난다).
- `role`에는 모델 이름을 적지 않는다. 모델은 바뀔 수 있고, 실제 모델은 `roster`의 모델 칸이 보여 준다.
